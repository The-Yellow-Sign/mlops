# 🛠 Гайд по работе с инфраструктурой полигона

Данная инструкция описывает процесс получения доступа к основным сервисам (GitLab, PostgreSQL) и правила безопасности проекта.

## Принцип доступа: Белые списки (Whitelist)

Для обеспечения безопасности все порты сервера закрыты для внешнего мира. Доступ предоставляется индивидуально для каждого IP-адреса участника команды.

### Как включить свой IP в белый список:

1. **Узнайте свой текущий IP:** Зайдите на сайт [2ip.ru](https://2ip.ru) или выполните `curl ifconfig.me` в терминале.
2. **Запрос доступа:** Передайте ваш IP-адрес администратору проекта (через Telegram).
3. **Ожидание:** Администратор внесет ваш адрес в настройки фаервола (UFW).

---

## Доступ к GitLab

GitLab развернут по адресу: `https://the-yellow-sign.duckdns.org`

### Особенности подключения:

* **Веб-интерфейс:** Доступен через браузер сразу после внесения вашего IP в белый список.

---

## Доступ к Базе Данных (PostgreSQL)

Доступ к БД также настроен через белые спискию

**Параметры подключения:**

* **Host:** `the-yellow-sign.duckdns.org`
* **Port:** `5432`
* **User/Password/DB:** Уточните у администратора (хранятся в `.env` файле проекта).
