# Дорожная карта: Настройка инфраструктуры VDS (GitLab + DB)

Проект по развертыванию полигона разработки с доступом по белым спискам IP-адресов.

---

### Этап 1: Базовая безопасность (UFW)

**Цель:** Закрыть сервер от внешнего мира и разрешить доступ только администратору.

* [x] Установка и активация `ufw`.
* [x] Настройка политики `default deny incoming`.
* [x] Создание правил для SSH.
* **Опыт в процессе:** Обнаружены лишние правила `Anywhere` и `v6`, которые открывали порты всему интернету в обход белого списка. Проведена очистка до состояния "только мой IP".

### Этап 2: Развертывание БД (PostgreSQL)

**Цель:** Поднять контейнер с базой данных и прокинуть порт для команды.

* [x] Создание `docker-compose.yml` на VDS.
* [x] Настройка публикации портов `5432:5432`.
* [x] Проверка подключения через внешний клиент (pgAdmin).
* **Опыт в процессе:** Изучена работа в терминале через `nano`. Разобрана логика "публикации порта" (внешний vs внутренний).

### Этап 3: Домен и DNS

**Цель:** Связать динамический домен с IP-адресом сервера.

* [x] Регистрация субдомена на DuckDNS.
* [x] Настройка A-записи на IP сервера.
* [x] Проверка связи через `ping`.

### Этап 4: Реверс-прокси (Nginx) и GitLab

**Цель:** Скрыть GitLab за Nginx для управления трафиком и SSL.

* [x] Установка Nginx на хост.
* [x] Создание конфигурации в `sites-available`.
* [x] Перевод GitLab на локальный интерфейс `127.0.0.1`.
* **Опыт в процессе:** Ошибка `502 Bad Gateway` и `Connection reset by peer`. Выявлен конфликт протоколов: GitLab пытался сам обрабатывать HTTPS, в то время как это должен делать Nginx. Исправлено заменой `external_url` на `http`.

### Этап 5: Шифрование трафика (SSL)

**Цель:** Защитить передачу данных и получить "зеленый замок" в браузере.

* [x] Установка `certbot`.
* [x] Временное открытие порта 80 для верификации.
* [x] Генерация сертификата Let's Encrypt для DuckDNS домена.
* **Опыт в процессе:** Понимание того, что Certbot автоматически модифицирует конфиги Nginx, добавляя правила для порта 443.

---

### Итоговый стек технологий:

* **OS:** Ubuntu (VDS)
* **Firewall:** UFW (Whitelist mode)
* **Containers:** Docker, Docker Compose
* **Web:** Nginx (Reverse Proxy)
* **SSL:** Certbot (Let's Encrypt)
* **Apps:** GitLab CE, PostgreSQL 18-alpine
